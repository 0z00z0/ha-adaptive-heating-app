# Adaptive Heating app

The app half of Adaptive Heating for Home Assistant. It holds the schedule, the house modes, the learning and the
settings pages, reached from **Heating** in the sidebar.

It needs the [Adaptive Heating integration](https://github.com/0z00z0/ha-adaptive-heating), which gives each room its thermostat. Install the integration first.

## Add this repository

1. Open **Settings → Apps → Repositories** and add `https://github.com/0z00z0/ha-adaptive-heating-app`, or use
   [this link](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2F0z00z0%2Fha-adaptive-heating-app).
2. Install the app and start it.

Needs the Supervisor and a 64-bit board (`aarch64` or `amd64`).
