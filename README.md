# Adaptive Heating app

The Adaptive Heating app holds the schedule, the house modes and the settings pages.

It works with the [Adaptive Heating integration](https://github.com/0z00z0/ha-adaptive-heating). The [install steps](https://github.com/0z00z0/ha-adaptive-heating#install) cover both.

Needs the Supervisor and a 64-bit board (`aarch64` or `amd64`).
